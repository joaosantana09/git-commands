## Como clonar um repositório

passo a passo:

```bash
# Navegando até o disco C
cd c/

# Criando uma pasta
mkdir Minha-pasta

# Entrando na pasta
cd minha-pasta

# Clonando o repositório
git clone <lin-repositório>

# Acessando o repositório
cd <path-repositorio>
```
